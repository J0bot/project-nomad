## 0. L'axiome — bion / tsoin / T+S+ION

José pose un seul axiome, et il tient debout des deux côtés :

> **Le bion = l'information, toute l'information, atemporelle. Le tsoin = le bion synchronisé à un instant = T+S+ION = Temps + Synchronisation + Ion.**

Traduit dans deux cadres physiques réels — et littéralement câblé dans le moteur :

- **Côté relativité (univers-bloc).** L'ensemble des événements 4D existe atemporellement comme une structure géométrique (Einstein-Minkowski). Un « instant » n'est qu'une tranche de simultanéité — un hyperplan `t = const` — et cette tranche **n'est pas canonique** : elle dépend de l'observateur. Le **bion = la structure complète** ; le **tsoin = une tranche**. C'est exactement la relation univers-bloc / foliation.
- **Côté information (Shannon).** L'information d'un état est définie indépendamment de *quand* on la lit. Un tsoin qui ne stocke que le **résidu = la surprise** (`popcount(s XOR g()) / |s|`, [`docs/thesis/04-tsoin-engine.md` §4.3](docs/thesis/04-tsoin-engine.md)) est le contenu en information de l'écart prédiction/réel — du codage prédictif propre.
- **Côté moteur.** Un tsoin est un couple `(générateur, résidu)` content-adressé : `addr64(gen, residu)` ([`ploxions/sdk/src/bions.rs:507`](ploxions/sdk/src/bions.rs)). Le **générateur** est la règle atemporelle régénérable (« le générateur EST la connaissance ») ; le **résidu** est ce que le réel ajoute à un instant ; le **`GatedTick`** fournit le `t` logique ([`clock-coherence/src/lib.rs`](ploxions/clock-coherence/src/lib.rs)). La reconstruction est vérifiable : `addr(reconstruct(tsoin)) == addr(s)`.

**Forme canonique correcte (un mathématicien la dirait ainsi).** « bion × temps » n'est **pas** un produit cartésien — le bion est atemporel, il ne peut pas être un facteur symétrique du temps. La structure cohérente est une **fibration** : soit `B` l'espace des bions (générateurs déterministes content-adressés), `T` la base = le temps-cohérence (les `t` produits par `GatedTick`), et l'espace total `E = { (g, r) }` muni de la projection d'oubli `π : E → B`, `π(g, r) = g`. Un **instant** du réel est une **section locale** `σ : U ⊆ T → E`, et `tsoin(t) = σ(t) = (g, résidu_t)`. Le « × temps » est l'**évaluation de la section en `t`**, pas une multiplication. C'est la traduction exacte de « le générateur EST la connaissance ; le résidu est ce que `t` ajoute ».

**Honnêteté sur « T+S+ION ».** La formule est un **acrostiche** (Temps + Synchronisation + Ion), une étymologie poétique — **pas** une décomposition dimensionnelle ni une équation. Le *contenu* qu'elle pointe (bion atemporel + index temporel + résidu) est, lui, propre et à moitié codé. Et « toute l'information » est une **asymptote** : voir §1 (Bekenstein, Heisenberg).
